# My Music Website

A simple website to share my music creations.

## Description
This website showcases my music hobby with a simple interface to play my creations.

## Structure
- `index.html` - Main page with music library
- `style.css` - Styling for the website
- `script.js` - JavaScript functionality
- `/songs` - Directory to store music files

## Setup
1. Clone this repository
2. Add your music files (MP3, WAV, etc.) to the `songs` directory
3. Open `index.html` in a web browser to listen to your music

## Features
- Simple, clean interface
- Responsive design
- Music player with basic controls
- Easy to add new tracks
